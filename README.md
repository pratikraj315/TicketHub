
# TicketHub

A movie and event ticket booking backend built using Java 17 and Spring Boot.

## Tech Stack

- Java 17
- Spring Boot
- Spring Data JPA / Hibernate
- Spring Security
- MySQL
- Maven
- JWT Authentication

## Project Status

🚧 Under Development

## Planned Features

- User registration and login
- Role-based authentication (USER / ADMIN)
- Movie and theatre management
- Show and seat management
- Seat locking with a 5-minute hold
- Booking confirmation and cancellation
- Booking history
- Concurrent seat booking protection
